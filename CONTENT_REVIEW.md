# Updated guide conversion notes

## Source and structure

This edition follows the Word guide updated November 7, 2026. The public guide
contains the introduction, seven tasks, and the overview sections in the same
sequence as the source document. The AI Receptionist overview stays between
Tasks 2 and 3; the Customer Assist overview stays between Tasks 3 and 4. The
call-in instructions stay with Task 5, before Task 6.

All 92 distinct embedded images are preserved across 93 screenshot placements.
The 12 Word tables are retained as six data tables and six note or tip callouts.
Images are copied from the updated document without recompressing them, so the
red callouts and labels remain part of their source screenshots.

## Credential guidance

The source includes sample account and password information in its instructions
and screenshots. The guide preserves those samples. It also tells participants
to use the session-specific values in `Session_Info.txt` instead of the values
shown in screenshots.

## Validation scope

The updated site is checked with a strict MkDocs build, local link and anchor
validation, and a count of screenshot placements and unique image files. These
checks do not sign in to dCloud, Control Hub, Webex, or a gateway, and do not
verify the current behavior of those services.
